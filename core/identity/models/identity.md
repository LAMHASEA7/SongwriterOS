# Identity Model

Version: 0.1


## Purpose

Defines who interacts with CreativeOS.


## Entities


## User

Represents a person using the system.


Attributes:

- id
- name
- role


---

## Workspace

Represents a creative environment.


Examples:

- Personal Workspace
- Studio Workspace


---

## Permission

Controls access.


Examples:

- Create
- Edit
- Review
- Publish


---

## Principle

Identity is independent from applications.
